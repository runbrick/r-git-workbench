# Rebased 主窗口视觉 Parity 差异盘点

对应 `docs/ROADMAP.md` P2 任务。基线：`D:\privateProject\rebased\screenshot.png`（1583x919）。本文档只覆盖视觉/布局层面，不重复 `docs/REBASED_ACTION_INVENTORY.md`（P1）里的动作功能盘点。`docs/UI.md` §8"Viva 缺口"列出的三方合并视图、Diff 上下排列等框架能力缺口已有独立跟踪，本文档引用但不重复列为新发现。

整体结构对照（`shell.go:805-822`，`Paint` 回调）：当前代码已经是 `Column{ TopBar, Row{ NavRail, ChangesSidebar?, Content }, StatusBar }` 的五段式布局，和 Rebased 的区域划分大体对应，但每个区域内部的控件密度、顺序、分组都有具体差距。

| 项 | Rebased 基线 | cetacean 现状 | 差异 |

## 汇总：P2 验收待办清单

按优先级列出需要新增/调整的具体项，用于后续直接动手改代码。

**P0（功能性缺陷，不只是视觉，应优先修）**
1. Copy SHA 按钮点击无动作 — `shell.go:1722`，需补上复制到剪贴板的处理逻辑。
2. Amend 复选框在界面上找不到触发入口 — 需在 `paintChangesSidebar` 或 `paintChangesDiff` 补一个 `f.Checkbox` 绑定 `m.amend`，否则 ROADMAP 记录的"已实现 Amend"用户实际摸不到。
3. 文件状态字母徽标完全缺失 — `paintGroup`（`shell.go:1805`）只画文件名文字，没有 M/A/D/R/U/? 徽标，同时是规格 §4.2 功能要求和 §8 无障碍要求的缺口。

**P1（视觉结构性差异，影响 parity 验收）**
4. Log 筛选工具栏从四行表单压缩为单行工具栏+标签式已选条件（对照"Text or hash / .* / Cc / Branch: HEAD ✕ / User▾ / Date▾ / Paths"）— `paintLog`，`shell.go:1632-1672`。
5. Log 详情区的文件列表改为树形结构，复用或新建类似 `paintChangesTree` 的组件 — `shell.go:1725-1740`。
6. Commit/Shelf 标签缺少选中态下划线/背景样式 — `shell.go:1247-1252`。
7. 文件分组标题缺复选框和折叠交互（"Changes N files"/"Unversioned Files N files"）— `paintGroup`，`shell.go:1805-1815`。
8. 提交详情区缺结构化展示（作者链接、两个时间戳、"In N branches"），当前整段消息文字堆在一起 — `shell.go:1760-1764`。
9. 顶部工具栏信息架构调整：移除常驻横排 Pull 策略按钮组，改为分支/同步相关的下拉弹层；补齐仓库切换器下拉箭头、分支选择器下拉弹层、设置齿轮、搜索图标化 — `paintTop`，`shell.go:846-920`。
10. 左侧窄轨道的图标语义需要和用户确认：当前是视图导航（六个页面），基线像是全局工具轨道（同步/分支/文件/更多/终端），两者定位不同，不能只换图标了事，需先决定导航入口搬到哪里。
11. 补"在外部终端打开"命令入口（对应左轨道的终端图标），同时是 P1 功能清单里缺失的一项。
12. Log 分支侧栏折叠为竖排标签条，取代当前 `m.width >= 1000` 的硬阈值隐藏 — `shell.go:1585-1586`。

**P2（细节/待确认）**
